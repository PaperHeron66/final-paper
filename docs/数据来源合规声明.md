## 一、获取方式合规性

1. 仅使用数据源官方提供的 ZIP 一次性下载文件，解压后本地读取，对应代码为 `scripts/01_load.py`。
2. **未使用任何爬虫技术**：未使用 Scrapy、Selenium、requests 配合网页解析、模拟登录抓取等任何形式的网页抓取行为，也未调用非官方镜像站或第三方转载地址。
3. 未调用任何需要账号鉴权的接口（如 Kaggle API、Tushare Token），因此不涉及凭证保管问题。
4. 数据获取环节不涉及任何网页抓取行为，符合课程作业对「白名单方式」的要求。

## 二、许可与使用范围

1. 数据集以 CC BY 4.0 协议发布，允许在署名前提下共享、改编与商业使用。本项目已在论文参考文献与 README 中给出规范署名与 DOI。
2. 本项目对数据的使用限于课程作业的学术分析，未用于任何商业用途。
3. 未对原始数据做再分发：仓库中不包含原始 Excel 文件，仅保留下载地址与校验说明，需要者可按上述地址自行获取。

## 三、隐私与伦理

1. 数据为零售商脱敏后的交易流水，仅包含发票号、商品编码、数量、单价、日期时刻、客户编号与国家，**不含姓名、电话、地址、邮箱等任何个人身份信息**。
2. 客户以 5 位数字编号标识，无法回溯到自然人，因此不涉及《个人信息保护法》意义上的个人信息处理。
3. 分析结论以聚合形式呈现（分层、占比、留存率、规则），未对任何单一客户做画像披露；气泡图等客户级图形均在坐标轴上做了抽样与匿名化处理。

## 四、可复现说明

- 随机种子固定为 `SEED = 42`（`scripts/config.py`）。
- 全量事实表参与计算，未抽样；仅在客户气泡图（随机抽取 6,000 位客户）与箱线图抖动散点（每国最多 400 点）两处抽样，方法已写入论文 3.3 节。
- 清洗、分析、绘图、论文生成全部由 `run_all.py` 一键复现，中间结果落盘于 `outputs/tables/`，论文中每个数字均可回溯到对应 CSV。
